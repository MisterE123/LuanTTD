# Transport & World Guide

Open **Controls → Transport & World Guide**, **Survey → Transport & World
Guide**, or enter `/workbenches`. Select a transport or world topic to see
how to start a route and which facilities, cargo or vehicles it needs.
**Open …** goes to the relevant hotbar without buying or building anything.

The construction tools and services do not require setup flags. Some
routes need industries, a connected waterway, a vehicle available in the
current year, or both stations in a suitable catchment. On the local
world setup screen, choose a named scenario for a guaranteed industry
layout, or let the generator place towns and industries.
