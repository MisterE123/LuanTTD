# Workbenches & Scenarios

From the native hotbar, open **Controls (6) → Workbenches & Scenarios (2)**,
or **Survey (1) → Workbenches & Scenarios (3)**. It is also available from
the Controls card or with `/workbenches`. Select a category and then an entry
for practical first steps, exact Luanti setting names and limits.

The status describes the current world. **Live** is an ordinary tool;
**Preview** is a narrower, runnable native feature. **Off** or **Setup
needed** shows which setting or prerequisite is missing. **Saved only**
means existing infrastructure can remain even when the current mode does
not allow more construction. **Fresh world** and **Separate world** are
literal: the index won't change an existing world into that scenario.

**Open …** sends the hotbar to the named, mounted workbench. It does not
issue a construction, purchase or vehicle order. Escape or **Back to world**
closes the index without changing the hotbar; normal hotbar slot **8 Back**
continues to work after opening a linked workbench. The index never changes
server settings, world configuration, company cash or a save.

For the independent Farm, Oil and Timber Goods chains, use separate fresh
seed-1751 worlds. Original stock map surveying is a separate read-only
SQLite world and needs a local verified terrain mask bank. The index gives
the setup and commands without trying to launch it from a shared company
campaign. Use the Original three-bus market row to find the start year,
then the adjacent breakdown and service rows for their restart controls.
